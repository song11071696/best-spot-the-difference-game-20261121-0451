Spot the Difference is a complete browser game with three hand-drawn scenes — a retro diner, a night-train sleeper and a clockmaker's workshop — each hiding 7 differences between two side-by-side pictures, with a countdown timer, hints, streaks and a star-rated win screen. All art is drawn procedurally on canvas and all sounds are synthesized with WebAudio.
## Run it
```sh
node serve.ts
```
